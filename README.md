

# ✅ Task Management System  

The **Task Management System** is a simple yet powerful tool that helps users organize their tasks efficiently by allowing them to add, update, and delete tasks for **today** and **tomorrow**.  

## 🔹 Key Features  

- **📝 Task Management:** Easily create, update, and delete tasks stored in two separate tables: "Today's Tasks" and "Tomorrow's Tasks."  
- **🔔 Notification System:** Receive browser notifications when tasks are due, with optional sound alerts.  
- **⏳ Countdown Timer:** Displays the remaining time for each task to ensure timely completion.  
- **🚨 Overdue Marking:** Tasks that are overdue are visually marked in **red** with a ✅ tick icon for easy identification.  
- **🔄 Auto-Fetching:** Automatically retrieves and displays tasks for today and tomorrow from the database.  

This system enhances productivity by keeping users on track with their tasks while ensuring they never miss important deadlines.
